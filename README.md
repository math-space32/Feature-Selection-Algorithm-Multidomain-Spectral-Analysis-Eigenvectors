# Optimizing Machine Learning Models for Cyberattack detection using Multidomain Spectral Analysis and Eigenvectors

## Aim
The aim of this paper is to create a feature selection algorithm that uses the concepts of correlation coefficient functions, Discrete fourier transform, Hilbert transform, and Eigenvectors to extract useful patterns and relaionships between the features, which could enable very effective feature selection resulting in highly accuracy Machine Learning models for detecting cybersecurity attacks.
